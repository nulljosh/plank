# Plank Money

How Plank makes money. The company plan is `REVENUE.md` in the Code root; the ledger is `GTM.md`.

## Price and rail

None. Plank has no App Store record and no checkout. It is free.

## What is actually sold

Nothing. The compiler is public to read and use. Plank is the language Joshua Tree apps are written in, and it is the first step toward letting other developers write for the platform.

## Who pays and why

Nobody. The people who use Plank are developers who want a small compiler they can read in a sitting. It is free because the code is the pitch, and the platform needs the language.

## Cost to serve

No paid API. The `ai` module in the language calls Anthropic or a local server with the user's own key, so Plank costs nothing to serve. The landing is a static page on Cloudflare.

## Where we are

- Plank is a teaching compiler and a portfolio piece (the old file), and now the language Joshua Tree apps are written in.
- The Homebrew tap `plank-lang` is the install path (repo notes).
- Revenue: no verified number (the App Store Connect key cannot read sales yet). Plank has no store record, so there is nothing to read.

## Role in the company plan

GTM.md lists it as the language Joshua Tree apps are written in, with no store record. It serves Stage 4 of REVENUE.md, where developers write for Joshua Tree. That stage has not started.

## Next

None for money. Plank is the seed of Stage 4, not a product, and that stage is not started.

## Million, billion, trillion

**A million.** Plank is a small language a few thousand developers use to write for Joshua Tree, and it earns nothing directly.

**A billion.** Plank is the language the platform's developers write in, and the platform takes a commission on what they sell.

**A trillion.** Plank is one of the languages the platform is built on, and the money comes from the platform's store.

## Change it

No price exists, and no file sets one. There is no App Store record to change.

Anyone who got Plank while it was free keeps it free.
