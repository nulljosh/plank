A compiled language you can read in an evening.

Functions, ints, floats, bools, strings, loops. One file turns them into a native binary. LLVM does the hard part. You get to read the rest.

fib.pk
fn fib(n: int) -> int {
  if n < 2 { return n }
  return fib(n - 1) + fib(n - 2)
}

fn main() {
  for i in 0..15 {
    print(fib(i))
  }
}
Terminal

  






  
Why it exists

  
Building a language sounds like a year of work. Real compilers are a hundred thousand lines you will never finish. Tutorials stop right before the part where a binary comes out. Plank is the missing middle: a real compiler, native output, small enough that the whole thing fits in your head.

  
No interpreter, no bytecode. Source becomes LLVM IR, LLVM optimizes it, your system linker finishes the job. The same road a production compiler takes, in a much smaller car.






  
What is in the box

  
Four types: int, float, bool, str. No implicit conversions, so no surprises. let binds once, var can change. if, else, while, for over a range, break and continue. Functions in any order, recursion included. Errors that name the file and line and tell you what to do instead. Compiled output is real machine code: fib(35) runs in a few hundredths of a second.

  
The compiler is one Python file on llvmlite. Lexer, parser, codegen, optimizer, link. Each is a plain function or class you can point at.






  
Run it

  
Needs uv and a C compiler for linking. The first run installs llvmlite on its own.


git clone https://github.com/nulljosh/plank && cd plank
./plank examples/fib.pk
./plank build examples/fib.pk
./plank emit examples/fib.pk
